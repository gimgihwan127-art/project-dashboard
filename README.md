# Project Board — 프로젝트 대시보드

프로젝트별 스케줄표, 카테고리(교육·영상·디자인·마케팅) 현황, 팀원 간 업무 요청을 한 화면에서 기록하고 공유하는 대시보드입니다.
설치할 것 없이 HTML 파일 3개(`index.html`, `style.css`, `app.js`)로 동작하고, 데이터는 구글 시트에 저장됩니다.

## 기능

| 영역 | 내용 |
|---|---|
| 프로젝트 탭 | 상단 `+`로 추가 · 탭 더블클릭 또는 제목 클릭으로 이름 변경 · 휴지통 아이콘으로 삭제 |
| 요약 카드 | 전체 진행률, 카테고리별 평균 진척도, 팀원별 진행 업무·받은 요청 수 |
| 일정 달력 | 스케줄표 위에 월별 달력으로 모든 업무를 시작일~종료일 막대로 표시(카테고리 색). 막대를 누르면 스케줄표의 그 줄로 이동 |
| 스케줄표 | 시작일을 달력에서 고르면 종료일로 자동 이동. 여러 개 생성 가능, 표 이름 변경 가능. 업무명·카테고리·담당자·기간·상태·진행률·메모 직접 입력, 타임라인 자동 표시, 최종 수정자 기록 |
| 엑셀 가져오기 | 스케줄표의 **엑셀 가져오기**로 내가 만든 엑셀(.xlsx/.xls/.csv) 일정표를 등록. 제목 줄과 열(업무명·구분·담당·시작/마감일·기간·상태·진행률·비고)을 자동으로 맞추고, 미리보기에서 열을 바꿀 수 있음. 병합 셀, `11/1~11/5` 같은 기간, `0%` 서식 지원. 없는 카테고리는 새로 만듦 |
| 자료 · 첨부 | 이미지·PDF를 올려 카드로 보고, 크게 보기(PDF는 페이지 넘김)·다운로드. 끌어다 놓기 가능, 최대 20MB. 파일은 시트 주인 드라이브의 '프로젝트 대시보드 첨부파일' 폴더에 저장되고 삭제하면 휴지통으로 이동 |
| 카테고리 현황 | 스케줄표에서 자동 요약(진행 중/예정 업무) + 현황 메모 + 앞으로 할 일 체크리스트. 카테고리 추가·이름 변경·삭제 가능 |
| 업무 요청·질문 | 받는 사람을 지정해 요청/질문 등록 → 요청됨·확인중·완료 칸반으로 관리, 답변 기록, 사람별 필터 |
| 수정 기록 | 우측 상단에 **내 이름**을 입력하면 모든 수정에 이름과 시간이 남습니다 |

## 저장 방식 (구글 시트)
- 모든 데이터는 구글 시트에 한 줄씩 저장됩니다. 토큰이나 로그인 없이 대시보드 주소만 열면 누구나 보고 고칠 수 있습니다.
- 수정하면 0.8초 뒤 **바뀐 칸만** 시트에 저장되므로, 여러 명이 동시에 고쳐도 서로 덮어쓰지 않습니다. (같은 칸을 동시에 고치면 나중에 저장한 쪽이 남습니다)
- 20초마다, 그리고 창으로 돌아올 때 최신 내용을 자동으로 불러옵니다. 입력 중인 칸은 건드리지 않고 입력을 마치면 화면이 갱신됩니다.
- 인터넷이 끊기면 브라우저에 보관했다가 다시 연결될 때 보냅니다. 우측 상단 표시: 동기화됨 / 저장 대기 / 저장 중 / 연결 오류
- `Ctrl+S`는 즉시 저장, ↻ 버튼은 즉시 새로고침입니다.

### 시트 구성
| 탭 | 내용 |
|---|---|
| 프로젝트 · 팀원 · 카테고리 · 할 일 · 스케줄표 · 스케줄 | 종류별로 한 줄씩. `프로젝트` 열로 프로젝트별 필터 가능 |
| 첨부파일 | 올린 이미지·PDF의 제목·파일명·드라이브ID·미리보기 (파일 자체는 드라이브 폴더) |
| 프로젝트 이름의 탭 | 그 프로젝트의 업무 요청·질문 (프로젝트 이름을 바꾸면 탭 이름도 따라 바뀜) |

시트에서 직접 고쳐도 대시보드에 반영됩니다. 단, **ID 열과 `…ID` 열은 고치지 마세요**(어느 데이터인지 구분하는 값). `프로젝트`·`카테고리`·`스케줄표` 같은 이름 열은 보기용이라 고쳐도 대시보드에서 다시 맞춰집니다. 탭 이름은 바꿔도 연결이 끊기지 않습니다.

## 처음 설치하기

### 1. 구글 시트 준비
1. 새 구글 시트 만들기 → **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 이 저장소의 `google-sheet.gs` 내용을 붙여넣고 저장
3. **배포 → 새 배포** → 유형 **웹 앱**, 실행 **나**, 액세스 권한 **모든 사용자** → 배포 (처음엔 권한 허용 필요)
4. 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `app.js` 맨 위 `DEFAULT_SHEET_URL`에 넣기

코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다(주소는 그대로).

### 2. GitHub Pages로 열기
1. GitHub에 저장소를 만들고 `index.html`, `style.css`, `app.js`를 올림
2. 저장소 **Settings → Pages** → Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소를 팀원에게 공유

시트가 비어 있으면 처음 연 사람의 데이터(저장소의 `data.json` 또는 예전 버전 데이터)로 채워집니다.

## 주의
- 웹 앱 주소를 아는 사람은 누구나 데이터를 읽고 쓸 수 있습니다. 대시보드 주소를 외부에 공유하지 마세요.
- 시트의 **파일 → 버전 기록**으로 이전 상태를 확인·복구할 수 있습니다.
- 백업: 📄 아이콘으로 JSON 파일 내보내기/가져오기가 가능합니다. (가져오기를 하면 시트 내용도 그 파일로 바뀝니다)
- 설정(톱니바퀴)에서 이 브라우저만 다른 시트에 연결할 수 있습니다.
