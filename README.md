# Project Board — 프로젝트 대시보드

프로젝트별 스케줄표, 카테고리(교육·영상·디자인·마케팅) 현황, 팀원 간 업무 요청을 한 화면에서 기록하고 공유하는 대시보드입니다.
설치할 것 없이 HTML 파일 3개(`index.html`, `style.css`, `app.js`)로 동작합니다.

## 기능

| 영역 | 내용 |
|---|---|
| 프로젝트 탭 | 상단 `+`로 추가 · 탭 더블클릭 또는 제목 클릭으로 이름 변경 · 휴지통 아이콘으로 삭제 |
| 요약 카드 | 전체 진행률, 카테고리별 평균 진척도, 팀원별 진행 업무·받은 요청 수 |
| 스케줄표 | 여러 개 생성 가능, 표 이름 변경 가능. 업무명·카테고리·담당자·기간·상태·진행률·메모 직접 입력, 타임라인 자동 표시, 최종 수정자 기록 |
| 카테고리 현황 | 스케줄표에서 자동 요약(진행 중/예정 업무) + 현황 메모 + 앞으로 할 일 체크리스트. 카테고리 추가·이름 변경·삭제 가능 |
| 업무 요청·질문 | 받는 사람을 지정해 요청/질문 등록 → 요청됨·확인중·완료 칸반으로 관리, 답변 기록, 사람별 필터 |
| 수정 기록 | 우측 상단에 **내 이름**을 입력하면 모든 수정에 이름과 시간이 남습니다 |

모든 입력은 즉시 브라우저에 자동 저장됩니다. 팀원과 공유하려면 아래 GitHub 동기화를 설정하세요.

## GitHub에 올려서 공유하기

### 1. 저장소 만들기
1. GitHub에서 **New repository** → 이름 예: `project-dashboard` → **Public** 선택 → Create
2. **Add file → Upload files**로 이 폴더의 `index.html`, `style.css`, `app.js`, `README.md`를 끌어다 놓고 Commit

### 2. 웹사이트로 열기 (GitHub Pages)
1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/project-dashboard/` 주소로 접속 가능 → 이 주소를 팀원에게 공유

### 3. 데이터 저장용 토큰 만들기 (수정하는 사람만)
1. GitHub 우측 상단 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. Repository access: **Only select repositories** → 이 저장소만 선택
3. Permissions → Repository permissions → **Contents: Read and write**
4. 생성된 토큰(`github_pat_...`)을 복사

### 4. 대시보드에서 연결
1. 대시보드 우측 상단 **로컬 저장** 버튼(또는 톱니바퀴) 클릭
2. 소유자(내 GitHub 아이디), 저장소 이름, 토큰 입력 → **설정 저장**
3. 처음 한 번은 ⬆ 버튼(**GitHub에 저장**, 단축키 `Ctrl+S`)을 눌러 `data.json`을 만듭니다
4. "변경 후 자동으로 GitHub에 저장"을 켜두면 수정할 때마다 4초 뒤 자동 업로드됩니다

팀원도 각자 자기 토큰으로 3~4번을 하면 함께 수정할 수 있습니다. 토큰 없이 접속한 사람은 마지막으로 저장된 데이터를 볼 수 있습니다.

## 동기화 동작 방식
- 데이터는 저장소의 `data.json` 한 파일에 저장되고, 저장할 때마다 GitHub 커밋 기록이 남습니다(이전 버전 복구 가능).
- 페이지를 열거나 다른 창에서 돌아오면 최신 데이터를 자동으로 불러옵니다(아직 올리지 않은 변경이 없을 때).
- 다른 사람이 먼저 저장한 경우 덮어쓰기 전에 알려줍니다. 이때는 ⬇ **불러오기**로 최신 데이터를 받은 뒤 다시 수정하세요.
- 같은 시간에 여러 명이 동시에 수정하면 나중에 저장한 쪽이 이깁니다. 자동 저장을 켜두면 충돌이 크게 줄어듭니다.

## 업무 요청·질문을 구글 시트로 관리하기 (선택)
업무 요청·질문은 구글 시트에 한 줄씩 저장할 수 있습니다. 프로젝트마다 시트 탭이 따로 생기고, 탭 이름은 프로젝트 이름을 따릅니다. 수정할 때 바뀐 칸만 저장하므로 여러 명이 동시에 고쳐도 겹치지 않고, 시트에서 직접 고쳐도 대시보드에 반영됩니다(20초마다 자동 갱신).

1. 새 구글 시트 만들기 → **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 이 저장소의 `google-sheet.gs` 내용을 붙여넣고 저장
3. **배포 → 새 배포** → 유형 **웹 앱**, 실행 **나**, 액세스 권한 **모든 사용자** → 배포 (처음엔 권한 허용 필요)
4. 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 대시보드 설정의 **구글 시트 연결**에 넣고 설정 저장 → GitHub에 저장
5. 기존 요청이 있으면 시트로 옮길지 묻습니다

웹 앱 주소는 `data.json`에 저장되어 팀 전체에 공유됩니다. 주소를 아는 사람은 요청을 읽고 쓸 수 있으니 주의하세요.

## 주의
- 토큰은 입력한 브라우저에만 저장되며 저장소에는 올라가지 않습니다. 공용 PC에서는 사용 후 설정에서 토큰을 지우세요.
- Public 저장소의 `data.json`은 누구나 볼 수 있습니다. 민감한 내용이 있다면 Private 저장소를 쓰세요(이 경우 GitHub Pages는 유료 플랜 필요, 대신 파일을 내려받아 로컬에서 열고 토큰으로 동기화하면 됩니다).
- 백업: 📄 아이콘으로 JSON 파일 내보내기/가져오기가 가능합니다.
